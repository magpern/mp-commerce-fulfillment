# User manual (v1.0.0)

Standalone end-user documentation for **MP Commerce Fulfillment** / **Commerce Fulfillment** `v1.0.0`.

## Open the manual

Open [`index.html`](index.html) directly in a browser (no build step, no CDN).

## Files

| Path | Purpose |
|---|---|
| `index.html` | Full user manual |
| `assets/manual.css` | Styles (print + responsive) |
| `assets/images/` | Reserved for optional screenshots (none required for v1.0.0) |

## Audience

Warehouse operators, warehouse leads, administrators / shop managers, and customer-service users who need order location context.

## Maintenance

Update this manual when a maintenance release (`v1.0.x`) changes operator-visible behaviour. Do not describe unimplemented or deferred features as current.

This folder is documentation only — it is not loaded by the WordPress plugin at runtime.
